SuperLocalMemory defends against sleeper agent attacks through a Bayesian trust scoring framework that monitors agent behavior and tracks memory provenance. In the sleeper agent scenario, an agent initially behaves normally, accumulating positive trust signals, but then begins to inject contradictory content. The system uses a decay factor to ensure that the early good behavior stabilizes the trust score. However, as negative signals from the poisoning phase accumulate, they gradually overcome the established baseline of trust.

Overall, the combination of behavioral monitoring and the Bayesian trust model allows SuperLocalMemory to actively defend against persistent memory poisoning by blocking agents with low trust scores from performing write and delete operations [Passage 9].

ANSWER:
NDCG, or Normalized Discounted Cumulative Gain, is a metric that evaluates the quality of ranked results by considering the relevance of items in a ranked list, distinguishing between high-relevance and low-relevance items within the same topic. This allows NDCG to provide a more nuanced assessment of ranking quality compared to MRR (Mean Reciprocal Rank), which treats all correct-topic results equally without regard to their relevance levels [Passage 1].

NDCG is considered a better metric than MRR for evaluating within-topic ranking quality because it accounts for the graded relevance of results, meaning it can differentiate between how relevant different memories are to a query. This is particularly important in scenarios where not all correct results are equally useful, as NDCG can reflect the ranking of the most relevant memories higher than those that are less relevant [Passage 1]. 

In summary, NDCG provides a more detailed evaluation of ranking quality by incorporating relevance levels, while MRR focuses solely on whether the first relevant result appears at rank 1, making NDCG more suitable for assessing the quality of ranked lists within a topic.

The cold-start problem in personalized ranking refers to the challenge of providing personalized recommendations or rankings when there is insufficient user data or feedback to inform the system. This situation often arises when a new user interacts with the system or when the system is newly deployed, leading to a lack of behavioral signals that are typically used to tailor the experience.

Synthetic bootstrapping is a technique that can help mitigate the cold-start problem by generating training data from existing memory patterns. This allows the system to achieve machine learning-grade personalization from the outset, even in the absence of real user feedback, thereby reducing the degradation in performance that typically accompanies cold-start scenarios [Passage 3]. However, while synthetic bootstrapping can provide initial data, it cannot fully substitute for genuine behavioral signals, which are necessary for effective learning in later phases [Passage 1]. 

In summary, synthetic bootstrapping aids in addressing the cold-start problem by enabling the system to start with a level of personalization based on synthetic data, but it is not a complete solution as it relies on real user feedback for ongoing improvement.
