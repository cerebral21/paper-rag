ANSWER:
The unified LTR (Learning-to-Rank) framework incorporates user behavioral signals such as clicks, add-to-carts, and purchases by treating these signals as engagement features within a channel-aware ranking model. This model is designed to jointly optimize multiple business objectives, including clicks, add-to-carts, and purchases, while also considering channel-specific objectives. The framework dynamically captures short-term intent shifts by incorporating recent user behavioral signals, which are critical for improving conversion rates in multi-channel ranking scenarios [Passage 1], [Passage 2], [Passage 3].

Additionally, the framework uses a weighted formulation to combine these engagement features, allowing for distinct aggregation and temporal decay to effectively capture short-term user interactions [Passage 4]. The experiments conducted for this framework utilized large-scale user interaction logs that included these behavioral signals, ensuring that the model is trained on relevant and recent data [Passage 6]. 

Overall, the integration of these user behavioral signals is central to the framework's ability to optimize for conversion in a dynamic and responsive manner.
